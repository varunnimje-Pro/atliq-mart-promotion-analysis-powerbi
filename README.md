# AtliQ Mart Promotion Analysis Dashboard

## Project Overview

This Power BI dashboard analyzes promotional campaign performance across stores and product categories.

The dashboard helps management evaluate:

- Promotion effectiveness
- Revenue uplift
- Incremental sales performance
- Store-level performance
- Product category performance

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Business Metrics

- Incremental Revenue
- Incremental Sold Units
- Store Performance
- Product Performance
- Promotion Effectiveness

## Key Insights

- Identified top-performing promotions.
- Analyzed revenue growth across stores.
- Evaluated discount effectiveness.
- Generated business insights to support decision-making.
